----------------
SSH ENUMERATION
----------------
- SSH es un protocolo de adminsitración remota que ofrece encriptación.
Se usa para acceder remotamente a servidores u ordenadores.
Puerto típico: 22.
Protocolo de transporte: TCP.
----------------
SMTP ENUMERATION
----------------
- Es el protocolo básico para la transmisión de mensajes de correo.
Puerto típico: 25.
Protocolo de transporte: TCP.
Se pueden usar modulos auxiliares para enumerar cuentas de usuario en la máquina víctima.(daemon,admin,root,www-data...)
